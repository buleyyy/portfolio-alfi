# 🚀 Personal Portfolio - Alfi Fauzi

Welcome to my personal portfolio repository! This website showcases my journey as an Information Systems student, my professional experiences, and the technical skills I've developed in web development and data analytics.

## 🌐 Live Demo
Check out the live site here: **[https://portfolio-alfi-six.vercel.app/](https://portfolio-alfi-six.vercel.app/)** *(Ganti link ini kalau link kamu berbeda)*

## 🛠️ Tech Stack
This project is built using modern web technologies:
* **Framework:** [Next.js 15](https://nextjs.org/)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/)
* **Icons:** [Lucide React](https://lucide.dev/)
* **Deployment:** [Vercel](https://vercel.com/)

## ✨ Features
- **Responsive Design:** Optimized for mobile, tablet, and desktop views.
- **Dynamic Experience Timeline:** Clear visualization of professional and organizational journey.
- **Project Showcase:** Highlights key technical projects and skills.
- **Fast Performance:** Leveraging Next.js App Router and optimized assets.
